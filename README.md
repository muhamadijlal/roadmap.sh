## Daftar Project

| Project | Deskripsi |
| --- | --- |
| [folder.info](./folder.info) ([project page](https://roadmap.sh/projects/nodejs-folder-info)) | CLI Node.js untuk menampilkan informasi folder: path, jumlah file, dan jumlah sub-folder. |
| [file.counter](./file.counter) ([project page](https://roadmap.sh/projects/nodejs-file-counter)) | CLI Node.js untuk menghitung jumlah baris, kata, dan karakter dari sebuah file teks. |
| [github.profile.details](./github.profile.details) ([project page](https://roadmap.sh/projects/nodejs-github-profile-details)) | CLI Node.js untuk menampilkan detail profil publik pengguna GitHub: nama, username, URL profil, jumlah repo publik, dan followers. |
| [json.formatter](./json.formatter) ([project page](https://roadmap.sh/projects/nodejs-json-formatter)) | CLI Node.js untuk membaca file JSON, memvalidasinya, lalu menampilkannya dalam format rapi (indentasi 2 spasi). |
| [env.checker](./env.checker) ([project page](https://roadmap.sh/projects/nodejs-env-checker)) | CLI Node.js untuk memeriksa apakah environment variable yang disebutkan sudah di-set, dan menampilkan yang belum. |
| [task.tracker](./task.tracker) ([project page](https://roadmap.sh/projects/task-tracker)) | CLI Node.js untuk mengelola daftar task: tambah, ubah, hapus, tandai in-progress/done, dan tampilkan berdasarkan status. Data disimpan di file JSON. |
| [github.user.activity](./github.user.activity) ([project page](https://roadmap.sh/projects/github-user-activity)) | CLI Node.js untuk menampilkan aktivitas publik terbaru seorang pengguna GitHub (push, issue, pull request, star, dll.) dari GitHub API, dengan event yang sama digabung beserta jumlahnya. |
| [expense.tracker](./expense.tracker) ([project page](https://roadmap.sh/projects/expense-tracker)) | CLI Node.js untuk mencatat pengeluaran: tambah, lihat daftar, hapus, dan ringkasan total (keseluruhan atau per bulan). Data disimpan di file JSON. |
| [numbering.guessing.game](./numbering.guessing.game) ([project page](https://roadmap.sh/projects/number-guessing-game)) | CLI Node.js berupa game tebak angka 1-100 dengan tiga level kesulitan (Easy, Medium, Hard), petunjuk lebih besar/kecil di setiap tebakan, dan opsi main lagi. |
| [unit.converter](./unit.converter) ([project page](https://roadmap.sh/projects/unit-converter)) | Aplikasi web untuk konversi satuan panjang, berat, dan suhu. Backend Express menyediakan endpoint `POST /api/convert`, frontend memakai React (Vite + Tailwind CSS). |

Setiap project berada di foldernya masing-masing dan memiliki `README.md` sendiri yang menjelaskan cara instalasi dan penggunaan.

## Catatan

Project-project ini dikerjakan sebagai latihan mengikuti roadmap dan ide project dari [roadmap.sh](https://roadmap.sh/projects).
